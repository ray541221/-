# Codex 三方同步懶人包

用途：長期備份與修復同步設定。

同步目標：
- 本地：C:\Users\88692\Desktop\Codex
- GitHub：https://github.com/ray541221/codex-backup.git
- Google Drive：G:\我的雲端硬碟\codex-backup
- 排程：每天 06:00

怎麼用：
```powershell
.\一鍵安裝或修復全部同步.ps1
```

平常手動同步：
```powershell
.\立即手動同步一次.ps1
```

排程壞掉才用：
```powershell
.\只修復每日0600自動同步.ps1
```

檔案用途：
- 一鍵安裝或修復全部同步.ps1：全部重建並同步
- 立即手動同步一次.ps1：立刻跑一次三方同步
- 只修復每日0600自動同步.ps1：只重建每天 06:00 排程
- 三方同步主程式.ps1：核心同步程式備份
- 安裝每日0600自動同步.ps1：排程安裝程式備份
