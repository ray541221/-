# AI 開發環境懶人包

用途：新電腦或重灌後，一鍵安裝 AI / 前端開發環境。

使用方式：
```powershell
.\AI開發環境一鍵安裝.ps1
```

會安裝：
- Git
- Node.js LTS
- Python 3.12
- VS Code
- GitHub CLI
- uv
- Docker Desktop
- pnpm
- VS Code Python extension
- PowerShell 執行權限設定
- 常用 PATH 設定
